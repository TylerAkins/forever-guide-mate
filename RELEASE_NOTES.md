## 0.1.2 - 2026-09-26

- Learned flight paths are remembered per land mass, so opening a flight master on Kalimdor no longer affects what is known on the Eastern Kingdoms.
- A distant flight listing no longer counts as a learned flight: an unlearned trip such as the Barrens run to Stonetalon keeps the road instead of sending you to a flight master.
- Added the addon-list icon.
